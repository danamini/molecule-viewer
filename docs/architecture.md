# How Molecule Viewer is built

A static site: `index.html`, `css/app.css`, ES modules in `js/`, and three.js r170 from jsDelivr through an
import map. No build step.

## Files

| File | What it does |
| --- | --- |
| `js/main.js` | The page: routing (`#key` addresses), the library, the details panel for every level, search, tour, guided journey, keyboard, landing page. |
| `js/stage.js` | The 3D stage: renderer, post-processing (ambient occlusion, bloom), camera, picking, and the dive between levels. |
| `js/structure.js` | Turns a library entry into a molecule model; ball-and-stick, space-filling and skeleton meshes. |
| `js/cloud.js` | Point-cloud rendering: molecule electron clouds, atomic orbitals (hydrogen-like, Slater-scaled), the shared shader. |
| `js/dive.js` | Levels below the molecule: atom, nucleus, nucleon. |
| `js/worlds.js` | Snowflake, periodic table (and its views), particle zoo, single particle, Planck scale. |
| `js/things.js` | The journey objects, their parts and hotspots, and inner levels (the Z80 die, the transistor). |
| `js/scale.js` | Magnification, everyday comparisons, the powers-of-ten ruler. |
| `js/elements.js`, `js/particles.js`, `js/facts.js` | Data: 118 elements, 17 particles, where you meet each element. |
| `js/sources.js` | Live PubChem search and Wikipedia summaries. |
| `molecules.js` | Generated by `tools/build_library.py`. Do not edit by hand. |

## Levels

Everything on screen is a *level*: an object with a `group` (three.js), a `radius` for framing,
`metresPerUnit` for the scale bar, `update(t)`, `fade(f)`, and usually `next(choice)`, which builds the
level inside it and says where in this level it sits. `stage.dive()` calls `next`, then animates the
outer level growing past the camera while the inner one grows in; `surface()` reverses it. The stack of
levels is the breadcrumb.

Chains in use:

- molecule → atom → nucleus (or electron) → nucleon → Planck length
- periodic table → atom → …
- particle zoo → particle → Planck length
- snowflake → ice → water molecule → …
- journey object → part's material (a molecule or crystal) → atom → …
- Z80 → die → transistor → material → …

## Adding things

- **A molecule:** add a row to `LIBRARY` in `tools/build_library.py` (PubChem name, group, Wikipedia
  title, one line on why it matters) and run `npm run build:library`.
- **A crystal:** write a builder returning atoms and bonds (see `gold()` or `quartz()`), add it to
  `CRYSTALS`, rebuild.
- **A journey:** add an entry to `THINGS` in `js/things.js` with a `model()` function, size in metres,
  the library key of its material, a blurb and stats. For hotspots, call `anchor(g, key, x, y, z)` in the
  model and list `parts`, each with a `child` library key or a `thing` key for a deeper drawn level
  (see `INNER`).
- **A table view:** add an entry to `TABLE_VIEWS` in `js/worlds.js` returning `{ color, rise, lit, scale }`
  for each element.

Run `npm test` after any change.
